# Changelog

All notable changes to NetGraph Studio are documented here.

## [Unreleased]

## [0.1.0] - 2026-08-19

### Added
- No-code Streamlit research workbench interface.
- City2Graph adapter architecture.
- Proximity and contiguity workflows.
- Urban morphology, OD/mobility, and GTFS workflow boundaries.
- Research/reproducibility result records.
- GeoJSON, CSV, GraphML, GML, and edge-list export paths.
- Automated fidelity, regression, import, validation, and upstream API contract tests.
- BSD 3-Clause licensing for NetGraph Studio.
- City2Graph third-party attribution and license notice.
- Academic software citation metadata.
- Streamlit deployment documentation.
