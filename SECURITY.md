# Security Policy

## Supported versions

Security fixes are prioritized for the latest version on the `main` branch.

## Reporting a vulnerability

Do not publish sensitive vulnerability details in a public issue. Contact the repository maintainer privately through the contact mechanism associated with the GitHub repository.

When reporting a security issue, include:

- affected version or commit;
- reproducible steps;
- affected workflow or component;
- expected and observed behavior;
- relevant logs or screenshots that do not contain secrets or personal data.

Please do not include API keys, passwords, access tokens, or private datasets in reports.
