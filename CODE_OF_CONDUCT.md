# Code of Conduct

## Our standard

Contributors and users are expected to communicate professionally, respectfully, and constructively. Scientific disagreement is welcome; personal attacks, harassment, discrimination, and deliberately disruptive behavior are not.

## Research-software expectations

When discussing results, contributors should distinguish clearly between measured evidence, reproducible test results, interpretation, and speculation.

## Enforcement

Project maintainers may moderate or remove contributions that violate this code of conduct or materially undermine a constructive research-software environment.
